# Image Compare

Локальна браузерна тулза для візуального порівняння 2, 3 або 4 зображень.

## Запуск

Відкрийте `index.html` подвійним кліком у сучасному Chrome, Edge або Firefox. Сервер і встановлення залежностей не потрібні.

## Керування

- Оберіть режим **2**, **3** або **4** у верхній панелі.
- Перетягніть файл у потрібну секцію або натисніть на секцію для вибору.
- У режимі 2 рухайте вертикальну лінію.
- У режимі 3–4 рухайте вертикальну, горизонтальну лінію або центральний маніпулятор.
- Стрілки клавіатури рухають активні роздільники на 1%; `Shift` + стрілка — на 5%; `R` повертає їх у центр.
- Подвійний клік по лінії або маніпулятору також повертає його в центр.
- **Вписати** показує зображення повністю, **Заповнити** заповнює всю область із можливим обрізанням країв.

## Колір та ICC-профілі

Зображення завантажуються з локального файла через Blob URL і показуються напряму в HTML-елементах `<img>`. Тулза не використовує canvas, не перекодовує файли та не видаляє їхні вбудовані ICC-профілі. Перетворення кольору виконує сам браузер.

Для передбачуваного результату потрібні актуальний color-managed браузер, коректний профіль монітора в операційній системі та формат зображення, який підтримує браузер. Файли нікуди не завантажуються і залишаються на комп’ютері.
