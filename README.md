# Image Compare

Локальна браузерна тулза для візуального та color-managed порівняння 2, 3 або 4 зображень.

## Запуск

Відкрийте `index.html` подвійним кліком у сучасному Chrome, Edge або Firefox. Сервер і встановлення залежностей не потрібні.

Усі декодери вже лежать у `vendor/`. Файли зображень не завантажуються в мережу.

## Формати

- Нативно через браузер: JPEG/JPG, PNG/APNG, WebP, AVIF, GIF, BMP, SVG.
- Через локальний декодер: TIFF/TIF, HEIC/HEIF, OpenEXR/EXR, Radiance HDR.
- TIFF: основна сторінка, RGB/Grayscale/CMYK, LZW/ZIP/JPEG/PackBits та інші компресії UTIF; preview має 8 біт на канал.
- HEIC/HEIF: основне зображення контейнера через `libheif`.
- EXR/HDR: linear float preview з Exposure від −8 до +8 EV і ACES, Neutral, AgX або Reinhard tonemapping.

## Керування

- Оберіть режим **2**, **3** або **4** у верхній панелі.
- Перетягніть файл у потрібну секцію або натисніть на секцію для вибору.
- У режимі 2 рухайте вертикальну лінію.
- У режимі 3–4 рухайте вертикальну, горизонтальну лінію або центральний маніпулятор.
- Стрілки клавіатури рухають активні роздільники на 1%; `Shift` + стрілка — на 5%; `R` повертає їх у центр.
- Подвійний клік по лінії або маніпулятору також повертає його в центр.
- **Вписати** показує зображення повністю, **Заповнити** заповнює всю область із можливим обрізанням країв.

## Колір та ICC-профілі

JPEG, PNG, WebP, AVIF та інші формати, які браузер підтримує сам, завантажуються через Blob URL і показуються напряму в `<img>`. Тулза не перекодовує їх та не видаляє вбудований ICC-профіль; перетворення кольору виконує браузер.

TIFF і HEIC/HEIF декодуються локально. RGB ICC-профіль або HEIF NCLX-опис переноситься у службовий PNG-preview, який потім color-manage-ить браузер. Якщо TIFF використовує профіль, несумісний із RGB-preview (наприклад CMYK), інтерфейс показує попередження про fallback-перетворення декодера.

EXR/HDR не є дисплейними ICC-зображеннями: float RGB перетворюється з визначеного EXR chromaticities/linear space у linear Rec.709, після чого застосовуються Exposure, tonemapping і sRGB transfer function.

Для передбачуваного результату потрібні актуальний color-managed браузер, коректний профіль монітора в операційній системі та формат зображення, який підтримує браузер. Файли нікуди не завантажуються і залишаються на комп’ютері.

## Перезбірка декодерів

Готова тулза не потребує Node.js. Він потрібен лише для оновлення vendor bundle:

```powershell
pnpm install
pnpm run build:codecs
```

Зафіксовані версії залежностей наведені в `package.json`, а ліцензії — у `THIRD_PARTY_NOTICES.md` і `vendor/`.
